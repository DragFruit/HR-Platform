# Шаблон заявления на отпуск (Word)

Файл **`vacation-application.docx`** — утверждённый бланк HR. Платформа подставляет данные при скачивании после согласования заявки (только **ТД**).

Копия для сборки Nitro: `server/assets/templates/vacation-application.docx` (синхронизируется скриптом `prepare-vacation-application-template.mjs`).

Пересобрать из исходника Word (жёлтые поля → теги): `node scripts/prepare-vacation-application-template.mjs [путь/к/исходнику.docx]`.

## Плейсхолдеры docxtemplater

| Плейсхолдер | Источник | Пример |
|-------------|----------|--------|
| `{legal_entity}` | `employees.json` → `legal_entity` | `Высокие Бизнес Идеи`, `ВиБиАй` |
| `{from_line}` | `title` + `name` | `аккаунт менеджер Иванов А.Н.` |
| `{employee_name}` | `name` | ФИО (для совместимости; в бланке — `{from_line}`) |
| `{position}` | `title` | Должность (для совместимости) |
| `{start_date}` | заявка → `start` | `15 января 2026 г.` |
| `{end_date}` | заявка → `end` | `28 января 2026 г.` |
| `{days_count}` | календарные дни между `start` и `end` | `14` |
| `{return_date}` | первый рабочий день после `end` (произв. календарь РФ) | `29 января 2026 г.` |

Даты — прописью на русском с суффиксом « г.». Число дней — **календарные** (как в тексте бланка).

## Не заполняются автоматически

Поля без жёлтой разметки в исходнике остаются для ручного ввода HR/сотрудником:

- номер и дата приказа;
- дата написания заявления и подпись сотрудника;
- дата согласования и подпись руководителя.

## Типографика подстановок

Плейсхолдеры в бланке — **Times New Roman**, кегль **11 pt** (`w:sz=22`), как основной текст заявления. Генератор не меняет шрифт соседних слов бланка.


## API

`GET /api/vacations/requests/:id/application` — скачивание для владельца заявки (`approved`) или admin/HR.
