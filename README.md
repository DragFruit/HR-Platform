# VBI HR Gamification

Внутренняя HR-платформа VBI: геймификация (задачи, валюта, магазин), адаптация, оргструктура и график отпусков. Сейчас это **демо на фронтенде** — данные в `localStorage`, без боевого API.

> **Документация:** этот файл — точка входа. Подробности: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md), история изменений: [docs/CHANGELOG.md](docs/CHANGELOG.md).

---

## Быстрый старт

1. Дважды кликните **`Open Frontend.command`** в корне проекта (macOS).
2. Откроется `http://127.0.0.1:3300/` — экран входа, затем полная платформа.
3. Чтобы остановить сервер — закройте окно терминала, которое открыл скрипт.

Альтернатива из терминала:

```bash
cd frontend
npm install
npm run dev      # разработка, http://localhost:3000
npm run build && NITRO_PORT=3300 node .output/server/index.mjs   # как в .command
```

## Оргструктура

Редактор и просмотр через **`OrgChart.vue`** — иерархия VBI:

- Три директора на одном уровне (финансовый, генеральный, коммерческий).
- Отделы (серые карточки), группы с общей рамкой (например блок «Анна Трубицына»).
- Перетаскивание блоков по сетке внутри колонки директора.
- Блок «VBI в цифрах» (факты) — опционально в данных.

Данные: composable `useOrgStructure.ts`, ключ **`vbi-org-structure-v1`**.

> Ранее был эксперимент с редактором «как Miro» (canvas 24×18, связи-линии). Он **откачен**; не восстанавливать без явного запроса.

## График отпусков

Логика перенесена с референса в `_vacation_source/График отпусков/`:

- Справочник сотрудников (`useEmployees`) — привязка к аккаунтам по email.
- Состояние заявок и календаря (`useVacations`) — согласование руководителем.
- Компоненты: `EmployeeVacationPanel`, `VacationTeamCalendar`, `VacationDetailedCalendar` и др.

Сид: `frontend/app/data/vacation-seed.json`.
