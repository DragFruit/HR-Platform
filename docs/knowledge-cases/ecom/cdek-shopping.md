# Кейс ecom: СДЭК ШОППИНГ

**Тег:** тематика еком

**Клиент:** СДЭК ШОППИНГ — Доставка товаров из 15 стран от известных брендов (e-commerce).

## Задачи
- Не более 3500 рублей CPS
- Стабильный объём заказов
- ДРР не выше пороговых значений по каждой категории товаров

## Проблемы
- Некорректно настроены коллтрекинг и передача данных в CRM
- Отсутствие посадочной страницы для оптовых продаж
- Фид товара сформирован с ошибками с таргетингом на Яндекс Маркет
- Динамические поисковые кампании и смарт-баннеры с высоким CPL

## Каналы
- Перфоманс реклама
- Посевы

## Что сделали
- Анализ прошлых рекламных кампаний (РК) клиента
- Определение общей стратегии РК
- Создание ТЗ на кастомизированные фиды по топ-товарам и отдельным фидам с лучшей ценой на рынке
- Запуск динрема по различным аудиториям с различными текстами
- Запуск видео-кампаний по отобранным роликам
- Отключение малоэффективных объявлений
- Создание отчёта в Power BI для оперативной аналитики

## Результаты
- На 61,97% больше заказов, ДРР соответствует плану
- CPS = 3 485 ₽
