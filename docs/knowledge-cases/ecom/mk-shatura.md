# Кейс ecom: МК Шатура

**Тег:** тематика еком

**Клиент:** МК Шатура — Мебельный бренд / розница и онлайн; продвижение новых и дорогих коллекций.

## Задачи
- Увеличение общего оборота по оффлайн-продажам
- Увеличение среднего чека более чем в 2 раза
- Реклама только новых, дорогих коллекций
- Запуск новых направлений с изготовлением на заказ (кухни, корпусная мебель)

## Проблемы
- Много мусорных запросов в бренде: компания созвучна с г. Шатура
- У пользователей Шатура ассоциируется с недорогой мебелью; отсутствие медийной поддержки усугубляло проблему
- Оценка результата на стороне клиента только суммарно по оффлайн-продажам (много факторов кроме интернет-рекламы)

## Каналы
- Контекстная реклама
- Таргетированная реклама
- Яндекс Карты

## Что сделали
- Стабильный рост оффлайн-продаж согласно оцифровке, оптимизация кампаний по этим данным
- Тестирование креативов, квизов, аудиторий

## Результаты
- Увеличение среднего чека (< 50 тыс. ₽ — ориентир из презентации)
- ДРР на желаемом уровне не более 30% только по онлайн-продажам
