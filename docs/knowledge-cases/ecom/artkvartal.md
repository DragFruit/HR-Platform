# Кейс ecom: Арт квартал

**Тег:** тематика еком

**Клиент:** Арт квартал — Интернет-магазин художественных товаров.

## Задачи
- Максимум заказов при CPO не дороже ~550 ₽
- Развитие регионов

## Проблемы
- Нехватка бюджета для ниши
- Конкуренты с более высокими бюджетами
- id товаров в фиде не совпадают с id в Метрике

## Каналы
- Контекстная реклама

## Что сделали
- Устранение недочётов в электронной коммерции и фидах
- Кампании по вендорным запросам различных категорий
- Использование микроконверсий из-за нехватки основных
- Объединение динамических кампаний в пакетную стратегию
- Ретаргетинг на посетителей определённых страниц со скидками в категории

## Результаты
- ДРР на желаемом уровне, не более 30%
