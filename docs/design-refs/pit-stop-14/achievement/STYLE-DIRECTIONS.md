# Стиль ачивок VBI — выбор направления (окт 2026)

Задача: один **системный** язык для всех ачивок платформы. Сейчас пробуем **чистые** направления по рефам заказчика — **без смешения** в одном кадре.

Пилот-сюжет: **Pit Stop 14 / топ-3** (клетчатый флаг, число 14). Текст названия ачивки в UI, не обязательно на иконке.

Палитра платформы (подставляем в любой выбранный язык): `#7451f4` · `#ddf365` · `#111` · `#eeeee8` · `#fff`.

---

## Направление A — «League / Bevel»

**Реф:** Duolingo Pearl League (розовый октагон с пером).

| Правило | Как |
|--------|-----|
| Форма | Многоугольник (hex / octagon), скруглённые углы |
| Объём | **Только bevel**: светлая грань сверху, тёмная снизу — «толстая конфетка» |
| Символ | Один простой силуэт по центру |
| Декор | 2–4 ромбика-sparkle рядом, не внутри символа |
| Запрет | Chrome/металл, лента с текстом, sunburst, фотореализм, глянец-пин |

**Сильные стороны:** яркий «вау» при мелком размере, единый ряд ачивок как лиги.  
**Риски:** слишком «игровой» рядом с ITMO-интерфейсом — проверить на `#eeeee8`.

Файл-проба: `style-A-league-bevel-pitstop.png`

## Направление B — «Flat medal»

**Реф:** GlowVerse «Blessed» (свеча в гексагоне).

| Правило | Как |
|--------|-----|
| Форма | Гексагон, толстая светлая обводка |
| Объём | **Нет** — чистый flat vector |
| Символ | 1–2 крупных плоских формы, почти иконочный |
| Декор | Минимум (1–2 точки-акцента) |
| Запрет | Bevel, градиенты, тени-объём, ленты, блёстки-звёзды |

**Сильные стороны:** спокойно, взросло, отлично масштабируется.  
**Риски:** может показаться «не вау» — вау даём цветом и формой, не бликами.

Файл-проба: `style-B-flat-medal-pitstop.png`

---

## Направление C — «Soft reward»

**Реф:** золотая звезда с «1».

| Правило | Как |
|--------|-----|
| Форма | Мягкая звезда / мягкий щит, «пухлые» углы |
| Объём | Два слоя (бордер + впадина), лёгкая тень у центрального знака |
| Символ | Крупная цифра **или** один символ |
| Декор | Несколько soft sparkles, опционально tab-лента сверху без текста |
| Запрет | Жёсткий металл, hex+лента GoodMates, sunburst |

**Сильные стороны:** тёплое «награда», дружелюбно.  
**Риски:** пастель может спорить с кислотным лаймом VBI — лайм держим насыщенным.

Файл-проба: `style-C-soft-reward-pitstop.png`

---

## Как выбираем дальше

1. Заказчик смотрит **A / B / C** в изоляции (не в коллаже со старыми пробами).
2. Выбранное направление → пишем **LOCKED rules** + эталон PNG.
3. Все новые ачивки только по LOCKED; без подмешивания других рефов.

Старые пробы (`icon-v2`, `wow-*`, flat ribbon) — черновики, **не** канон.
