# Визитка сотрудника (публичная карточка)

Формат: компактная ID-карточка / «права», поповер у клика. Не страница, без затемнения фона.

## Эталон

- `LOCKED-etalon-v1.png` — зафиксированный первый макет (композиция).
- `LOCKED-etalon-v1-close-avatar.png` — тот же формат + лаймовый крестик; в слоте — аватар персонажа с платформы.

## UI

Компонент `EmployeeVisitingCard.vue`, открытие:

```ts
openEmployeeVisitingCard(emp, event) // MouseEvent → якорь рядом с кликом
```

Поповер `position: fixed` у курсора; невидимый catcher без dim; Esc / × / клик снаружи.

## Точки входа

| Где | Статус |
|-----|--------|
| Календарь отпусков (ФИО) | подключено |
| Профиль → «Твоя команда» | подключено |
| Банк идей (автор карточки + топ авторов) | подключено |
| Структура (оргчарт) | позже |

## Содержание

ФИО · должность · отдел · в команде с / стаж · ДР (`birthday`) · ачивки · идеи · ссылки Вишлист (скоро) / Bitrix.  
Без телефона/почты, без отпусков/активности.
