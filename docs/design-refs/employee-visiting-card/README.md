# Визитка сотрудника (публичная карточка)

Формат: компактная ID-карточка / «права», поповер у клика. Не страница, без затемнения фона.

## Эталон

- `LOCKED-etalon-v1.png` — композиция (рамка, бейдж, поля, футер, barcode).
- `LOCKED-etalon-v1-close-avatar.png` — то же + лаймовый ×; в слоте — аватар персонажа платформы.

## UI (как в эскизе)

- Толстая чёрная рамка + квадратики лайм/фиолет по углам (не lime drop-shadow).
- Бейдж `VBI · СОТРУДНИК` — чёрная плашка, белый текст.
- ФИО капсом, `Unbounded`.
- Поля: лейбл слева / значение справа, даты `ДД.ММ.ГГГГ`, стаж «N ГОД(А) M МЕСЯЦ(А)».
- Футер в одну строку: Достижения + плитки | Идеи | Вишлист / Bitrix (фиолетовые ссылки).
- Декор-полоса «штрихкод» снизу.

Компонент: `EmployeeVisitingCard.vue`.

```ts
openEmployeeVisitingCard(emp, event) // MouseEvent → якорь рядом с кликом
```

## Точки входа

| Где | Статус |
|-----|--------|
| Календарь отпусков (ФИО) | подключено |
| Профиль → «Твоя команда» | подключено |
| Банк идей (автор карточки + топ авторов) | подключено |
| Структура (оргчарт) | позже |

## Содержание

ФИО · должность · отдел · в команде с / стаж · ДР (`birthday`) · ачивки · идеи (всего) · Вишлист (скоро) / Bitrix.  
Без телефона/почты, без отпусков/активности.
