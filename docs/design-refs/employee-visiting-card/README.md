# Визитка сотрудника (публичная карточка)

Формат: компактная ID-карточка, поповер у клика. Не страница, без затемнения.

## Эталон (источник правды)

- `LOCKED-etalon-v1.png` — композиция.
- `LOCKED-etalon-v1-close-avatar.png` — + лаймовый × и аватар персонажа в слоте.

**Правило переноса:** локал = эталон 1:1. Не «улучшать» и не менять композицию без нового LOCKED.

## Реализация

- `EmployeeVisitingCard.vue`
- Декор barcode: `frontend/public/employee-card/barcode-strip.png` (вырезан из эталона)
- Рамка: толстая чёрная + квадратики лайм/фиолет в полосе рамки + лаймовый ×
- Бейдж чёрный, ФИО Unbounded капсом, поля label/value, футер: Достижения | Идеи | Вишлист | Bitrix
- Открытие: `openEmployeeVisitingCard(emp, event)` у курсора
