# База знаний — дизайн-референс

Moodboard карточек (архив): `kb-cards-moodboard.png`.

Эталон поиска: [abit.itmo.ru/bachelor](https://abit.itmo.ru/bachelor) — «Найти программу мечты»: поле-pill + чёрная кнопка, чипы как Бюджет/Контракт.

## Реализация

Страница: `/knowledge` (`frontend/app/pages/knowledge/index.vue`).  
Сид: `frontend/app/data/knowledgeBaseCatalog.ts`.  
Статья: `/knowledge/[id]`.

## Экран сейчас

- Пустой холст, поиск снизу, консоль ~2/3 ширины.
- Переключатель режимов — два pill (лайм = активный): «По базе» / «Спросить ИИ».
- Строка: белый pill-инпут + чёрная кнопка «Искать» / «Спросить».
- Фильтры классики — чипы (дата, автор, тематика, регламент, FAQ).
- ИИ: чат, в каждом ответе ссылки на статьи (`useKnowledgeAiAnswer`).
