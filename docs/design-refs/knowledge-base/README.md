# База знаний — дизайн-референс

Moodboard карточек (архив): `kb-cards-moodboard.png`.  
Актуальный экран: поиск снизу, два режима плашками.

## Реализация

Страница: `/knowledge` (`frontend/app/pages/knowledge/index.vue`).  
Сид: `frontend/app/data/knowledgeBaseCatalog.ts`.  
Статья: `/knowledge/[id]`.

## Экран сейчас

- По умолчанию пустой холст.
- Снизу две перекрытые плашки: **Найти по базе…** / **Спросить ИИ**. Задняя при смене выходит сверху вперёд.
- Классика: фильтры над строкой (дата, автор, тематика, тип). Выдача — только название + подсветка.
- ИИ: чат как VPN, без фильтров. В каждом ответе ссылки на статьи (`useKnowledgeAiAnswer`).

## Стиль

ITMO / платформа: лайм `#ddf365`, фиолетовый `#7451f4`, чёрная обводка 2px, тень 4×4, Unbounded на заголовках выдачи.
