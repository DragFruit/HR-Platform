# База знаний — дизайн-референс

Moodboard: `kb-cards-moodboard.png`.

## Реализация

Страница: `/knowledge` (`frontend/app/pages/knowledge/index.vue`).  
Сид: `frontend/app/data/knowledgeBaseCatalog.ts`.

## Что взяли из референса

- Силуэт **папки**: выступ-вкладка слева сверху, ступенька вправо.
- Сетка **карточек**: бейдж во вкладке → крупный заголовок → описание → автор / VBI.
- Шевроны `>>>` в правом нижнем углу.
- Слот «+ новые материалы…» с пунктирной рамкой (без папочной формы).
- Вариант «документ-превью» со списком пунктов.

## Адаптация под VBI HR

Цвета платформы (лайм `#ddf365`, фиолетовый `#7451f4`, чёрная обводка 2px, тень 4×4, ITMO-квадратики). Hover анимирует **всю карточку**.
