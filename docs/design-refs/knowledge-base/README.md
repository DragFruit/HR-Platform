# База знаний — дизайн-референс (бэклог)

Сохранено на будущее: раздел ещё собирается, это **moodboard / идея направления**, не финальный UI платформы.

## Файл

`docs/design-refs/knowledge-base/kb-cards-moodboard.png`

## Что взять на заметку

- Сетка **карточек** (не таблица): категория-бейдж сверху, крупный заголовок, короткое описание, автор/мета внизу.
- Цветные градиентные плашки + светлые диагональные блики.
- Декор в углу (шеврон / паттерн) — мягкий, не спорит с текстом.
- Один слот-заглушка «+ новые материалы…» с пунктирной рамкой.
- Есть вариант «документ-превью» (белая карточка со структурой содержания).

## Адаптация под VBI HR

При реализации переносить **структуру и ритм карточек**, а цвета/тона — в палитру платформы (лайм `#ddf365`, фиолетовый `#7451f4`, чёрная обводка, ITMO-квадратики), а не копировать оранжево-розовые градиенты референса один в один.

Hover: как у плиток профиля — анимировать **всю карточку**, не внутренние объекты.
