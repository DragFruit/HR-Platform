Эталон поиска: карточка «Найти программу мечты» на [abit.itmo.ru/bachelor](https://abit.itmo.ru/bachelor).

## Как у ITMO, как у нас

| ITMO | VBI |
|------|-----|
| Серая скруглённая карточка | то же, grain `#e4e4de` |
| «Найти программу мечты» (не меняется) | «Найти в базе» (не меняется) |
| Бакалавриат / магистратура / аспирантура | Поиск / Спросить ИИ (активный = чёрный pill) |
| Поле + чёрная «ИСКАТЬ» | то же; в ИИ — «Спросить» |
| Чипы отраслей | Отпуска, Адаптация, Банк идей + иконка фильтра |
| Карточка по центру | карточка снизу по центру — общее для поиска и чата; выдача/диалог сверху слева |

Фильтры в UI выключены (код оставлен). В строке — печатающаяся подсказка. Справа сверху выезжает оценка страницы.

Страница: `/knowledge`. Сид: `knowledgeBaseCatalog.ts`.
