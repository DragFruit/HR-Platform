# База знаний — дизайн-референс

Эталон поиска: карточка «Найти программу мечты» на [abit.itmo.ru/bachelor](https://abit.itmo.ru/bachelor).

## Как у ITMO, как у нас

| ITMO | VBI |
|------|-----|
| Серая скруглённая карточка | то же, grain `#e4e4de` |
| «Найти программу мечты» | «Найти в базе» / «Спросить ИИ» |
| Бакалавриат / магистратура / аспирантура | По базе / Спросить ИИ (активный = чёрный pill) |
| Поле + чёрная «ИСКАТЬ» | то же; в ИИ — «Спросить» |
| Чипы отраслей | быстрые тематики (Отпуска, Адаптация, Банк идей, Документ) + иконка фильтра |

Тип, период, автор и остальные тематики — в окне по иконке фильтра, поверх карточки поиска. Выдача — по левому краю.
