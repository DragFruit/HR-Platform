# Маскот Vibe (послеотпускная памятка)

Официальный маскот **Vibe** для post-vacation memo и дальнейших носителей платформы.

Источник стиля: **Design C** (`series-c-01` … `series-c-06`).

## Что это

Минималистичный домашний кот: flat silhouette в оттенках eggplant / lavender, рядом чемодан и растение. Уютный, спокойный, «свой» — не корпоративный персонаж и не мультяшная карикатура.

## Визуальные правила

| Да | Нет |
|----|-----|
| Flat purple silhouette, мягкие формы | Жирные чёрные обводки / neo-brutalist stroke |
| Уютный домашний вайб (чемодан, растение, окно, стол) | «Приютный» кот, грязный реализм, жалость |
| Палитра: **lime** `#ddf365` + **lavender** фон карточки + **eggplant** `#3b1f5e`–`#4a2c6a` | Очки и карикатура серии B |
| Закрытые глаза / лёгкая мимика линиями | Photoreal, 3D clay, толстые контуры |
| Листья и детали **внутри** границы карточки (на сайте — clip) | Вылезшие за край элементы в финальном ассете |

Акценты UI на карточке (бейдж «Совет», кнопка «Дальше») — lime; маскот и предметы — purple flat без чёрной рамки.
