## Берём в ближайшие итерации

1. ~~**Сценарии адаптации**~~ — каталог + создание/правка/назначение на `/admin/adaptation`.
2. **Магазин:** фильтр по стоимости.
3. **База знаний:** каркас раздела + первые статьи (отпуска, оргсхема, onboarding) — ценность = наполнение.
4. **Профиль:** блоки «О работе» / руководитель рядом с командой (вместо сводки «Сейчас»).

## Не копируем слепо

K-Team — надстройка **над** коробочным Bitrix. Vibe — отдельный фронт с интеграцией. Не тянем КЭДО, SCORM и Copilot, пока нет запроса и контента.
