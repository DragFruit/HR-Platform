# VBI Copy — тексты платформы

Читай этот скилл целиком перед черновиком. Детали голоса и шаблоны — по ссылкам ниже, только если нужны.

## Цель

Текст, который **звучит как живой человек из VBI**, а не как шаблон HR-системы или ChatGPT. Одна мысль — одно предложение. Уважение к пилоту отпусков и к времени сотрудника.

## Когда включать

- Любые UI-строки, empty/error/loading, онбординг, CTA.
- Колокольчик / `/notifications` / Bitrix `im.notify` / тексты чат-бота (не путать канал: согласование ≠ чат).
- Надписи на мерче, купоне, баннере магазина.

**Не** менять бизнес-правила (`PRODUCT.md`) без явного ок заказчика.  
**Не** верстать и не рисовать — отдать слоты ui-ux / product-design.

## Workflow

```
- [ ] 1. Канал и слот (UI / notify / merch / письмо)
- [ ] 2. Задача читателя (что сделать / что узнать / что почувствовать)
- [ ] 3. Черновик 1–3 вариантов (короткий → ещё короче)
- [ ] 4. Self-check (ниже) — выкинуть воду
- [ ] 5. Сдача: таблица «где → текст» + при необходимости A/B
```

### 1. Канал задаёт длину

| Канал | Лимит духа | Пример |
|-------|------------|--------|
| Кнопка / таб | 1–3 слова | «Подать заявку» |
| Empty state | заголовок + 1 фраза + CTA | без эссе |
| Ошибка | что случилось + что сделать | без «упс» |
| Уведомление | факт + ссылка/действие | без «уважаемый» |
| Bitrix-колокольчик | ещё короче, чем в платформе | см. PRODUCT / BITRIX |
| Мерч | 2–6 слов, читается с 1 м | без мелкого абзаца |

### 2. Голос (жёстко)

**Делай:** прямой тон; «ты» к сотруднику в продукте; конкретные даты/числа; глагол вперёд.  
**Не делай:** канцелярит («осуществить», «в рамках»), AI-воду («в современном мире», «важно отметить»), фальшивый энтузиазм («Супер! 🎉»), англицизмы без нужды, давление («немедленно», «обязательно сегодня»).

Полная матрица do/don't и антипаттерны: [references/voice.md](references/voice.md).

### 3. Self-check перед сдачей

Пройди список; если хоть один «да» на запрет — перепиши:

1. Можно убрать половину слов без потери смысла? → убери.
2. Есть абстракция вместо факта? («скоро», «некоторые») → конкретизируй или спроси.
3. Звучит как письмо из 1С / госзакупки? → перепиши разговорно.
4. Есть эмодзи «для тепла»? → почти всегда нет (исключение — только если уже принято в этом экране).
5. Конфликт с `PRODUCT.md` / правилами Bitrix-уведомлений? → остановись, спроси.
6. Для мерча: читается ли с телефона на расстоянии вытянутой руки?

### 4. Формат сдачи

```markdown
| Место (экран / ключ / канал) | Текст | Заметки |
|------------------------------|-------|---------|
| … | … | вариант B: … |
```

Коротко: зачем такой тон (1 предложение), если неочевидно. Дальше — контролёр.

## Связь с ролями

- Назначение в задаче: «копирайтер» → этот скилл.
- UI без финального текста → слоты + черновик-заглушка, не финальный маркетинговый абзац.
- Мерч → согласовать длину с product-design.
