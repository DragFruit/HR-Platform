# Шаблоны копирайта VBI

Подставляй конкретику. Не оставляй плейсхолдеры в финале.

## Empty state

```
Заголовок: [что отсутствует, 2–5 слов]
Текст: [зачем раздел + один следующий шаг]
CTA: [глагол]
```

Пример:
- Заголовок: «Пока нет идей»
- Текст: «Предложи улучшение — коллеги смогут проголосовать.»
- CTA: «Предложить идею»

## Ошибка

```
[Что сломалось]. [Что сделать пользователю].
```

Пример: «Не удалось отправить в Битрикс. Попробуйте ещё раз или напишите HR.»

Не: «Произошла непредвиденная ошибка. Повторите попытку позднее.»

## Уведомление в платформе

```
[Кто/что] — [суть]. [Действие или период].
```

Пример: «Маша подала отпуск 12–18 августа — на согласование.»

## Bitrix system notify

Короче платформы на ~20%. Без markdown-романов. Ссылка в конце одной строкой, если нужна.

## Онбординг / первый вход

1 экран = 1 мысль.  
Приветствие → зачем платформа в одном предложении → CTA («Выбрать аватар» / «К отпускам»).

## Мерч / купон / баннер

- Заголовок: польза или повод (`5 лет в VBI`), не описание товара.
- Подзаголовок: опционально, ≤12 слов.
- CTA на кнопке: «Использовать», «Заказать», не «Узнать подробнее».

## Варианты A/B

Когда сомневаешься — сдай **два** коротких варианта с пометкой:
- A — нейтральный факт
- B — чуть теплее (без пафоса)

Не сдавай 5 синонимичных абзацев.
