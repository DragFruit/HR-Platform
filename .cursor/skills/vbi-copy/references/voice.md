# Голос VBI — reference

Читать, когда сомневаешься в тоне или ловишь «AI-голос».

## Кто говорит

Платформа — коллега из HR/продукта, который ценит время. Не корпоративный портал, не реклама банка, не «дружелюбный бот».

Обращение: **ты** в сотрудницком UI. **Вы** — только если заказчик явно просит (официальные письма вовне).

## Do / Don't

| Do | Don't |
|----|-------|
| «Заявка у руководителя» | «Ваша заявка направлена на согласование ответственному лицу» |
| «Не хватает 2 дней» | «К сожалению, недостаточно доступного остатка» |
| «Войдите через Битрикс24» | «Авторизуйтесь посредством корпоративного портала» |
| «Собрать набор к юбилею» | «Инициировать процесс комплектации gift set» |
| «Пока пусто — предложи идею» | «Здесь пока нет контента. Самое время проявить инициативу! ✨» |

## Запрещённые штампы (вырезать сразу)

- «В современном мире / в наше время»
- «Важно отметить / следует подчеркнуть»
- «Бесшовный / инновационный / экосистема»
- «Поздравляем с успешным…» без конкретного повода
- «Не стесняйтесь обращаться»
- Двойные смягчения: «пожалуйста, будьте добры, по возможности…»
- Англ. UI-кальки: «сабмитнуть», «аппрувнуть» в пользовательском тексте (в коде — ок)

## Эмоциональный регистр по зоне

| Зона | Регистр |
|------|---------|
| Отпуска / согласование | Спокойный, ясный, без давления |
| Ошибки / Bitrix sync fail | Прямой, без паники и без обвинения пользователя |
| Идеи / магазин | Чуть живее, всё ещё без крика |
| Юбилей / ачивка | Тепло, коротко, без пафоса «легенда компании» |
| VPN / доступы | Сухой инструктаж |

## Числа и даты

- Дни отпуска, сроки, лимиты — цифрами: `28`, `3 недели`, `15.08`.
- Не «около месяца», если есть точная дата из продукта.

## Согласование vs чат-бот (не путать тексты)

- Согласующим по заявке — системное уведомление (колокольчик), тон: «на согласование», факты.
- Сотруднику/руководителю напоминания от бота — см. PRODUCT §1.3.1; не смешивать формулировки каналов.
